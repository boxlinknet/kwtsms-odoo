kwtSMS Gateway

Send SMS via kwtSMS.com directly from your Odoo instance

Odoo 19 English + Arabic GCC Optimized

Overview

Replace Odoo's default IAP SMS provider with kwtSMS (kwtsms.com), Kuwait's leading SMS gateway. Automatically send SMS notifications when sales orders are confirmed or deliveries are completed. Supports multilingual templates (English and Arabic), full audit logging, and phone number normalization for GCC countries. Test mode included for safe development.

Key Features

🔌

Direct API Integration

Subclasses Odoo's SmsApiBase to route all SMS through kwtSMS. No IAP credits needed.

📦

Business Event SMS

Auto-send SMS on order confirmation and delivery completion. Toggle each trigger independently.

🌐

Multilingual Templates

Pre-built English and Arabic templates with placeholder support: order name, amount, tracking, and more.

📞

GCC Phone Normalization

Converts Arabic/Hindi digits, strips prefixes, validates 7-12 digit numbers. Handles +965, 00965 formats.

📊

Full Audit Log

Every SMS logged with status, API response, points charged, balance remaining. Auto-cleanup via cron.

✅

Test Mode

Safe development with test mode ON by default. Messages queued but not delivered, no credits consumed.

How It Works

1

Install and Configure

Install the module, go to Settings, enter your kwtSMS API username and password, then click "Login / Verify".

2

Select Sender ID

Pick your registered sender ID from the dropdown. Your sender IDs are fetched automatically from kwtSMS.

3

Enable Triggers

Toggle "SMS on Order Confirmation" and "SMS on Delivery Completion". Assign templates for each event.

4

Go Live

Turn off Test Mode when ready. SMS will be delivered to customers automatically on each business event.

Send SMS from Any Record

Use the built-in SMS Compose wizard to send a quick message from any partner, sale order, or delivery. Select a template or type a custom message. Character count and SMS page calculation shown in real time.
