Replace Odoo IAP SMS with Kuwait's leading gateway. Direct API, multilingual templates, full audit trail.

ODOO 19 EN + AR GCC READY FREE

kwtSMS Gateway integrates kwtsms.com directly into your Odoo instance. Automatically send SMS when sales orders are confirmed, deliveries completed, invoices posted, or payments received. Supports multilingual templates (English and Arabic), complete audit logging, and phone number normalization for 93 countries. Test mode included for safe development.

Key Features

⚡

Direct API Integration

Connects directly to the kwtSMS REST API. JSON-based, POST-only, with automatic retry and rate limiting (2 req/sec).

🔔

Business Event SMS

Auto-send on order confirm, cancellation, delivery, invoice, and payment. Each trigger toggleable independently.

🌐

Multilingual Templates

10 pre-built templates in English and Arabic. Dynamic placeholders for customer name, order, amount, tracking.

📱

Phone Normalization

Validates 93 countries. Converts Arabic/Hindi digits, strips prefixes (+965, 00965), normalizes 7-12 digit numbers.

📈

Full Audit Log

Every SMS logged: status, API response, points charged, balance remaining, message ID. Auto-cleanup via cron.

🛠

Test Mode Built-in

Test mode ON by default. Messages queued but not delivered, zero credits consumed. Safe for staging.

Setup in 4 Steps

01

Configure

Enter your kwtSMS API username and password, then click Login to verify.

02

Sender ID

Select your registered sender ID from the dropdown (auto-populated after login).

03

Enable Triggers

Toggle SMS for orders, deliveries, invoices, and payments. Each event is independent.

04

Go Live

Turn off Test Mode. SMS will deliver automatically on every business event.
