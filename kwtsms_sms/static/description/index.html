kwtSMS Gateway

YOU SEND. WE DELIVER.

Send SMS via Kuwait's leading SMS gateway directly from Odoo. Direct API integration, multilingual templates, full audit logging.

ODOO 19 EN + AR GCC READY

kwtSMS Gateway integrates kwtsms.com, Kuwait's leading SMS gateway, directly into your Odoo instance. Automatically send SMS notifications when sales orders are confirmed, deliveries completed, invoices posted, or payments received. Supports multilingual templates (English and Arabic), full audit logging, and phone number normalization for GCC countries. Test mode included for safe development.

Key Features

⚡

Direct API Integration

Connects directly to the kwtSMS API for fast, reliable SMS delivery across the GCC region.

🔔

Business Event SMS

Auto-send on order confirm, delivery, cancellation, invoice, and payment. Toggle each independently.

🌐

Multilingual Templates

Pre-built English and Arabic templates with placeholders: order name, amount, tracking, and more.

📱

GCC Phone Normalization

Converts Arabic/Hindi digits, strips prefixes, validates 7-12 digit numbers. Handles +965, 00965 formats.

📈

Full Audit Log

Every SMS logged with status, API response, points charged, balance remaining. Auto-cleanup via cron.

🛠

Test Mode

Safe development with test mode ON by default. Messages queued but not delivered, no credits consumed.
